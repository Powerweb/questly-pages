配達クエスト進捗アプリ

Questly

テンプレートからクエストを作り、開始・終了と達成を手元と CarPlay で追います。

できること

Uber Eats やロケットNow などの配達クエストを、手入力のテンプレートから生成して管理します。
外部 API 連携や自動取込はありません。データは端末の中だけです。

テンプレ種別・必要回数・報酬・エリア・時間帯などを手入力し、そこから実クエストを作ります。固定サンプルとマイテンプレートを分けて表示します。
進捗進行中・開始待ち・終了した一覧で見渡します。「あと◯分で開始｜終了」、段階バーや横並びスロットで達成を追えます。
受託受託時刻を記録し、適用中のカードに表示します。キャンセルは受託を外すだけ、完了は達成を1回足してから外します。
プラットフォームUber Eats / ロケットNow などを設定し、バッジ表示名（絵文字可）を編集できます。作成・受託時に対象を選べます。
CarPlay進行中クエストを車の画面で一覧します。買い切り B で Now Playing 表示、C で秒付き時計と相対時間の秒表示が使えます。
保存クエスト・テンプレート・設定・購入状態は iPhone の中（SwiftData / UserDefaults）だけです。アカウントはありません。この版に iCloud はありません。
無料初回はクエスト登録が2件までです（作成・複製とも）。閲覧と編集は続きます。
有料日本の顧客価格は税込みで、各買い切り ¥320 です。A クエスト無制限、B CarPlay Now Playing、C 秒表示。購入画面に出る価格は、そのときの店の表示価格です。

App Store の商品ページ URL は公開後に掲載します。購入価格はストア表示が優先されます。CarPlay の配布には Apple の Driving Task 承認が別途必要です。
