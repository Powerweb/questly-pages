プライバシーポリシー

Questly（以下「本アプリ」）のプライバシーポリシーです。

収集する情報

本アプリは、クエスト・テンプレート・設定・購入状態などを端末内（SwiftData / UserDefaults）に保存します。Uber Eats 等の外部配達サービスへのログイン情報や API 連携は行いません。

外部送信

現時点で、個人を特定するデータを当社サーバーへ送信する機能はありません。App Store 経由の課金は Apple の決済処理に従います。

CarPlay

CarPlay 表示は端末内のクエスト情報を車載画面に出すためのものです。音楽の再生操作は OS / CarPlay 側が行い、本アプリは曲情報の表示（該当プラン購入時）に限ります。

データの削除

アプリを削除すると、端末内に保存したクエスト等のデータは端末から削除されます。アカウント登録機能はありません。

解析と追跡

解析 SDK、広告、トラッキングはありません。

お問い合わせ

本ポリシーに関する問い合わせ: info@de3.in

変更

内容を変更する場合は、本アプリ内またはサポートページで周知します。

Questly

配達クエストの進捗を、手元と車で見渡すアプリです。
